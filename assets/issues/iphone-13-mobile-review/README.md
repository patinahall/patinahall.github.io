# iPhone 13 mobile review baselines

Captured from the public `https://patinahall.com` Storefront on 2026-08-15.
These images use headless Chromium mobile and touch emulation at 390 by 844
CSS pixels with a device scale factor of 1. They are comparison baselines, not
screenshots from a physical iPhone or evidence of Safari behavior.

The set covers the initial cookie choice, Home, open mobile navigation,
Catalog, the Entourage Finds Store page, and one Product gallery. The physical
iPhone 13 reproduction requested by the linked issue must record its iOS and
Safari versions and add real-device evidence before a fix is selected.
