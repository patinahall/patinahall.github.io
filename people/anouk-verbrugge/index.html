Frontend Engineer

Anouk Verbrugge

Anouk represents the point where PatinaHall's machinery becomes something a person can actually see and use. Her frontend work turns photographs, measurements, condition notes and seller context into an interface that feels calm without making one-off furniture feel generic.

  • Frontend engineering
  • Interaction design
  • Material character

Working principle

A calm interface should still let an object feel particular.

Clarity is not the same as removing every trace of character. The interface has to establish rhythm and confidence while leaving enough visual space for grain, wear, proportion and the seller's own point of view.

The profession

Building the layer people touch

Frontend engineering owns more than the final coat of colour. It decides how information is grouped, what happens when a buyer moves through a gallery, whether a seller understands the next action and how the same journey changes between a wide desk and a narrow phone.

For PatinaHall, that visible layer also carries responsibility. A price must not drift away from its context. A photograph should not hide behind ornamental interface chrome. A useful condition note has to remain readable before enthusiasm turns into a decision.

The vintage connection

Translating texture without pretending it can be touched

Vintage furniture is physical: wool catches light differently from velvet, oak grain changes across a surface and a shallow photograph can make a cabinet look smaller than it is. A screen cannot reproduce touch, so the interface has to support close looking instead of making impossible promises.

That means thoughtful image crops, honest scale cues, comfortable typography and a hierarchy that lets measurements and seller evidence sit beside beauty. Anouk's visual world combines interface fragments with wood, textile and ceramic samples because neither side should erase the other.

What this changes

Small screens still deserve the complete story

Many discoveries begin on a phone, where every extra panel competes with the object itself. The frontend role keeps the essential path intact: understand the piece, see who is offering it and continue to the independent store when it feels right.

The goal is not to make PatinaHall look like a design exercise. It is to make a complicated marketplace feel direct enough that attention can return to the furniture.
